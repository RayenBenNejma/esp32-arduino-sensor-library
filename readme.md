# 🔊 Ultrasonic Sensor Projects (HC‑SR04 with Arduino & ESP32)

## Overview
This repository demonstrates the versatility of the **HC‑SR04 ultrasonic sensor** through practical implementations on **Arduino Uno** and **ESP32** platforms.  
It includes both beginner and advanced examples, such as **obstacle avoidance robotics** and **smart water‑level monitoring**, designed for educational and environmental IoT applications.

---

## 🧠 Features
- Accurate distance measurement (2 cm – 400 cm range)
- Real‑time obstacle detection and avoidance
- Smart water‑level monitoring with IoT connectivity
- Temperature compensation for improved precision
- Modular and scalable design for integration with other sensors

---

## ⚙️ Hardware Requirements
| Component | Description |
|------------|--------------|
| HC‑SR04 Ultrasonic Sensor | 40 kHz transducer pair (VCC, GND, TRIG, ECHO) |
| Arduino Uno / ESP32 | Microcontroller boards used for testing |
| Breadboard & Jumper Wires | Circuit assembly and prototyping |
| Optional: LCD / OLED Display | Visual distance output |
| Optional: Wi‑Fi Module (ESP32 built‑in) | IoT data transmission and dashboard integration |

---

## 💡 Applications
### 1️⃣ Obstacle Avoidance Robot (Arduino)
An autonomous robot that detects and avoids obstacles using ultrasonic distance feedback.

### 2️⃣ Water Level Monitoring System (ESP32)
A smart IoT setup that measures tank water levels and transmits data to a cloud dashboard or mobile app.

---

## 📊 Troubleshooting Highlights
| Issue | Cause | Solution |
|--------|--------|-----------|
| Inaccurate readings | Temperature variation | Apply temperature compensation |
| No echo detected | Object too far or soft surface | Adjust timeout or use reflective target |
| Unstable values | Electrical noise | Add capacitor or shield wiring |
| Incorrect distance | Misaligned sensor | Mount level and perpendicular to surface |
